# CyberShield - Frontend

## Como rodar localmente

1. Instalem as dependências:
   ```
   npm install
   ```

2. Rodem o servidor de desenvolvimento:
   ```
   npm run dev
   ```

3. Acessem no navegador: http://localhost:5173

**Importante:** o backend precisa estar rodando na porta 8000 (veja o README da pasta /backend) para a tela mostrar "Backend respondeu: ok".
